# PlateReview UI 设计规范（极简扁平风 / Minimalist Flat）

> 上一版是风格派（De Stijl，粗黑网格 + 红黄蓝平涂），已废弃。
> 本文件描述当前生效的风格。

## 绝对禁止（违反即返工）

- 禁止任何**阴影**（零 shadow）
- 禁止任何**渐变**
- 禁止**透明度低于 0.5** 的颜色
- 禁止**混用圆角值**（本程序统一直角，即 `rounded-none`）
- 禁止**灰色文字**（仅允许刻意弱化的说明文字）
- 禁止**图案背景**
- 禁止 hover 时位移 / 缩放（不得制造 Z 轴错觉）
- 禁止柔和过渡（300ms 以上）；本程序用瞬时或 75ms

## 色彩

| Token | 值 | 用途 |
|---|---|---|
| 主色 | `#000000` | 文字、边框、填充按钮 |
| 背景 | `#FFFFFF` | 页面背景、卡片、输入框 |
| 强调色 | `#FF3366` | 仅用于 focus 边框、hover 文字、少量强调 |

只允许纯色。不使用灰底。

## 结构

- 边框：`border-2 border-black`（2px 纯黑实线）
- 圆角：全部直角
- 层次靠**留白**与**边框粗细**建立，不靠阴影
- 留白是硬性要求：区块之间大间距，容器内边距宽裕

## 排版

| 层级 | 处理 |
|---|---|
| H1 | 特粗、紧字距 |
| H3 | 粗体 |
| 正文 | 常规字重，行高舒展 |
| 标签 | 小号、大写、宽字距 |
| 弱化 | 仅用于说明文字 |

## 交互

- **按钮（填充）**：黑底白字 + 2px 黑边 → hover 反色为白底黑字
- **按钮（描边）**：白底黑字 + 2px 黑边 → hover 反色为黑底白字
- **输入框**：无边框，仅**底部 2px 黑线**；focus 时底线变强调色
- **active**：短暂浅色反馈
- 所有反馈都是**二维平面内的颜色反转**，不位移、不缩放

### 控件对应

| 元素 | 实现 |
|---|---|
| 证据图 | 2px 黑框，内部白底，图片等比放入；缩放为像素级（直接从原图绘制） |
| 检测车牌 / 确认车牌 | 真实 EDIT 子类化：白底、无边框、**仅底部 2px 黑线**，focus 变强调色 |
| 置信度 | 纯黑正文，只读 |
| 状态 | 2px 黑框小方块，内部平涂：白=待定、黑=是、强调色=否、浅灰=跳过 |
| 格式 | 合规=黑底白字 `OK`；不合规=强调色块 + 说明文字 |
| 是 / 否 / 跳过 | 见下 |
| 导航三按钮 | 描边按钮（白底黑字），hover 反色 |

按钮状态：

| 按钮 | 默认 | hover |
|---|---|---|
| 是 | 黑底白字 | 白底黑字 |
| 否 | 白底黑字 | 黑底白字 |
| 跳过 | 白底黑字 | 黑底白字 |
| 上一张 / 转至未确认 / 完成报告 | 白底黑字 | 黑底白字 |

## 自检清单

- [ ] 零阴影
- [ ] 零渐变
- [ ] 无低透明度颜色
- [ ] 圆角统一（全部直角）
- [ ] 留白充足
- [ ] hover 是颜色反转，不是位移/缩放
- [ ] 过渡瞬时或极短
- [ ] 高对比（黑白 + 单一强调色）
- [ ] 状态不只靠颜色传达（都带文字）
